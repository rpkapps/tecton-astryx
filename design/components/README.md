# Tecton component inventory

One file per component in this folder. Everything below was read off the Storybook screenshots in `screenshots/` (dark mode, captured at 2× device pixel ratio on a 1600px-wide page); colour values were sampled from the PNGs and cross-checked against `tokens/tecton.tokens.json`.

**32 components documented.** Foundations (colors / spacing-and-radius / typography, screenshots 114–116) and the welcome page (129) are covered elsewhere. Panel compositions (117–124) are in `../patterns/panels.md`.

## System-wide observations

- **Page background** `#1d1c1f`; **text** `#f7f6f8`; **focus ring** hot pink `#ff52a8`; **primary fill** violet `#5d4d68` lightening to `#80708b` when pressed/activated.
- **Disabled is not an opacity filter** on filled controls — the fill is replaced with a near-black recessed `#111012`.
- **Elevation runs dark**: menus, popups and panels are *darker* than the page, not lighter, and only FAB has a shadow.
- The emphasis vocabulary `primary / secondary / tertiary / outlined / textOnly` recurs across Button, ButtonGroup, IconButton, FAB and ToggleButton.
- The field vocabulary `Outlined / Filled / TextOnly` recurs across TextField, Select and Autocomplete, with the same seven states and the same dotted-underline disabled-filled signature.
- Sizes are named inconsistently: `md/sm` (Button), `Medium/Small` (most), `40/32/24/18px` (Avatar), `16/20/24px` (Icon), `large/medium/small/extraSmall` (ToggleButton), `lg/md/sm` implicit (Chip).
